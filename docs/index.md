# Discount Bot

Добро пожаловать в техническую документацию Discount Bot.

## О проекте

Discount Bot — система автоматизированного взаимодействия
с продавцами с целью получения наиболее выгодной цены
на выбранный товар.

## Возможности системы

- Поиск информации о товаре.
- Анализ предложенной цены.
- Ведение переговоров с продавцом.
- Запрос дополнительной скидки.
- Проверка итоговых условий сделки.
