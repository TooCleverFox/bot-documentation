# Обзор продукта

## Назначение

Discount Bot предназначен для автоматизации
переговоров между покупателем и продавцом.

## Участники взаимодействия

- Покупатель — инициирует запрос на получение скидки.
- Бот — анализирует условия и формирует предложения.
- Продавец — рассматривает предложение и принимает решение.
