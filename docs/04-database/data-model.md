# Модель данных

## 1. User

Хранит информацию о пользователях системы.

| Поле | Тип данных | Обязательное | PK | FK | Значение по умолчанию | Описание |
|---|---|---|---|---|---|---|
| id | UUID | Да | Да | Нет | Генерируется | Уникальный идентификатор |
| telegram_id | BIGINT | Да | Нет | Нет | — | ID пользователя Telegram |
| username | VARCHAR(255) | Нет | Нет | Нет | NULL | Имя пользователя |
| first_name | VARCHAR(100) | Нет | Нет | Нет | NULL | Имя пользователя |
| language_code | VARCHAR(10) | Нет | Нет | Нет | ru | Язык интерфейса |
| is_active | BOOLEAN | Да | Нет | Нет | TRUE | Статус пользователя |
| created_at | TIMESTAMP | Да | Нет | Нет | NOW() | Дата регистрации |
| updated_at | TIMESTAMP | Да | Нет | Нет | NOW() | Дата изменения записи |

## 2. Product

Хранит информацию о товарах, для которых запрашивается скидка.

| Поле | Тип данных | Обязательное | PK | FK | Значение по умолчанию | Описание |
|---|---|---|---|---|---|---|
| id | UUID | Да | Да | Нет | Генерируется | ID товара |
| user_id | UUID | Да | Нет | User.id | — | Владелец товара |
| name | VARCHAR(255) | Да | Нет | Нет | — | Название товара |
| url | TEXT | Да | Нет | Нет | — | Ссылка на товар |
| original_price | DECIMAL(12,2) | Да | Нет | Нет | — | Исходная цена |
| currency | VARCHAR(3) | Да | Нет | Нет | USD | Валюта |
| status | VARCHAR(30) | Да | Нет | Нет | pending | Статус обработки |
| created_at | TIMESTAMP | Да | Нет | Нет | NOW() | Дата добавления |

## 3. Negotiation

Хранит историю переговоров с продавцами.

| Поле | Тип данных | Обязательное | PK | FK | Значение по умолчанию | Описание |
|---|---|---|---|---|---|---|
| id | UUID | Да | Да | Нет | Генерируется | ID переговоров |
| product_id | UUID | Да | Нет | Product.id | — | Товар |
| seller_name | VARCHAR(255) | Да | Нет | Нет | — | Имя продавца |
| initial_price | DECIMAL(12,2) | Да | Нет | Нет | — | Начальная цена |
| proposed_price | DECIMAL(12,2) | Нет | Нет | Нет | NULL | Предложенная цена |
| final_price | DECIMAL(12,2) | Нет | Нет | Нет | NULL | Итоговая цена |
| status | VARCHAR(30) | Да | Нет | Нет | created | Статус переговоров |
| started_at | TIMESTAMP | Да | Нет | Нет | NOW() | Начало переговоров |
| completed_at | TIMESTAMP | Нет | Нет | Нет | NULL | Завершение переговоров |
